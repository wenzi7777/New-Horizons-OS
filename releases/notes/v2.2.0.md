# v2.2.0

**v2.0.F 新增電導輸出（µS）與雙向自動量程，只焊部分 Rfb 的板子不再被誤判為飽和，校正也能在電導模式下進行。原始 ADC mV 模式完全不變，仍是所有板子的預設。**

## 讀數模式（v2.0.F）

- `set_range` 的 `mode` 改為三種：`raw`（ADC mV，預設）、`conductance`（電導，µS）、`auto`（電導＋自動量程）。電導 G = (Vout − Vref − offset) / (Vref · Rfb)，Vref 與 Rfb 互相抵消，所以換 Vref 讀數不變。
- 電導與自動量程需要先跑 `rfb_measure`；沒有量到任何一列時回 `range_rfb_required`。沒有 Rfb 的列輸出 0。
- 移除 `virtual` 模式與參考 Rfb（`ref_rfb_ohm`）；送 `virtual` 回 `range_mode_removed`。**舊版存的 virtual / auto 設定在更新後一律重設為原始 mV、Vref 330 mV。**
- 改變單位時濾波器重新開始；離開 auto 或 `clear_rfb` 時 Vref 回到 330 mV。

## 只焊部分 Rfb

- `rfb_measure` 逐列回報狀態：`ok`、`no_feedback`（沒焊）、`saturated`、`open`、`adc_failed`，存入設定。
- 沒焊 Rfb 的列（運放開迴路貼軌）不再算進飽和與峰值，自動量程不會因此把 Vref 一路壓到 100 mV。

## 雙向自動量程

- 飽和時每步 ×0.8 往下，最低 100 mV。
- 連續 5 秒沒有飽和，且目前 Vref 下已觀察 5 秒，就依峰值預測往上（目標峰值 2000 mV，每步最多 ×1.25，增益不到 ×1.03 不動）。上限為 Vref 上限與 750 mV 取小者；每步至少間隔 400 ms，超過 1.5 秒的舊幀不算。
- 狀態新增 `auto_ceiling_mv`、`window_peak_mv`、`auto_steps`、`saturated_rows`、`saturated_frames`、`rfb_status`、`output_unit`。

## 每幀的量程資訊

- 串流封包（v5）新增 range 擴充欄位（type 0x02，8 bytes）：單位（mV / µS）、是否自動、該幀的 Vref、飽和列遮罩，放在 App 事件之前。只有 v2.0.F 會送。
- 電導模式下 `raw_adc` 區塊帶的是 ADC 讀數本身（未經補償），錄下來可以重算。`matrix_sample` 回覆新增 `unit`。

## 電導模式的校正

- 校正檔記住自己的單位（`unit`：mV 或 uS）；舊校正檔一律視為 mV，不受影響。
- 輸出單位與校正檔不同時，校正保留但不套用（`output_mode` 為 `raw`、`unit_matches` 為 false），切回原單位即恢復；此時 `calibration_enable` 回 `calibration_unit_mismatch`。空的校正檔不算不符。
- 新的校正 session 以當下的輸出單位進行；已存的校正檔是另一種單位時，草稿從空白開始，存檔後取代舊檔。session 期間不能改讀數模式（`set_range` 回 `calibration_session_active`），單位若仍改變則擷取與存檔回 `calibration_unit_changed`。
- 已存的壓力點是另一種單位時，單獨歸零回 `calibration_unit_mismatch`。
- µS 的讀出曲線固定為恆等式；擷取時 ADC 飽和的樣本記為飽和，多數區塊見過飽和的壓力點不納入擬合。沒焊 Rfb 的感測器標為 `no_rfb`（點狀態 `r`、`cells_no_rfb` 計數），不算失敗。
- 狀態新增 `unit`、`active_unit`、`unit_matches`、`draft_unit`。

## 相容性

- 不認得 range 欄位的舊版 Desktop / NH Studio 在不知道矩陣尺寸時，可能推算不出感測器數量。請一併更新到 Desktop v1.14.0 / NH Studio v2.10.0。
- 其他板子行為不變。
