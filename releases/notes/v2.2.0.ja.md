# v2.2.0

**v2.0.F に電導出力（µS）と双方向の自動レンジを追加しました。Rfb を一部の行にしか実装していないボードが飽和と誤判定されなくなり、電導モードでも校正できます。ADC mV の生値モードは変わらず、全ボードの既定値です。**

## 読み取りモード（v2.0.F）

- `set_range` の `mode` は 3 種類になりました：`raw`（ADC mV、既定）、`conductance`（電導、µS）、`auto`（電導＋自動レンジ）。電導 G = (Vout − Vref − offset) / (Vref · Rfb) は Vref と Rfb が打ち消し合うため、Vref を変えても値は変わりません。
- 電導と自動レンジには先に `rfb_measure` が必要です。測定済みの行がないと `range_rfb_required` を返します。Rfb のない行は 0 を出力します。
- `virtual` モードと参照 Rfb（`ref_rfb_ohm`）を削除しました。`virtual` を送ると `range_mode_removed` を返します。**旧バージョンで保存された virtual / auto の設定は、更新後すべて ADC mV・Vref 330 mV に戻ります。**
- 単位が変わるとフィルターを最初からやり直します。auto を抜けたときや `clear_rfb` のときは Vref が 330 mV に戻ります。

## Rfb の一部実装

- `rfb_measure` は行ごとに状態を返して保存します：`ok`、`no_feedback`（未実装）、`saturated`、`open`、`adc_failed`。
- Rfb のない行（オペアンプが開ループでレールに張り付く）は飽和とピークの判定から外れ、自動レンジが Vref を 100 mV まで下げ続けることがなくなりました。

## 双方向の自動レンジ

- 飽和すると 1 ステップ ×0.8 で下げます（下限 100 mV）。
- 5 秒間飽和がなく、現在の Vref で 5 秒観測したら、ピークから予測して上げます（目標ピーク 2000 mV、1 ステップ最大 ×1.25、×1.03 未満なら動かさない）。上限は Vref の上限と 750 mV の小さいほう。ステップ間隔は 400 ms 以上で、1.5 秒より古いフレームは使いません。
- 状態に `auto_ceiling_mv`、`window_peak_mv`、`auto_steps`、`saturated_rows`、`saturated_frames`、`rfb_status`、`output_unit` を追加しました。

## フレームごとのレンジ情報

- ストリームパケット（v5）に range 拡張フィールド（type 0x02、8 バイト）を追加しました：単位（mV / µS）、自動かどうか、そのフレームの Vref、飽和行マスク。App イベントより前に置かれ、v2.0.F だけが送ります。
- 電導モードの `raw_adc` ブロックは補正前の ADC 値そのものなので、記録から再計算できます。`matrix_sample` の応答に `unit` を追加しました。

## 電導モードでの校正

- 校正プロファイルが自分の単位（`unit`：mV または uS）を記録します。既存のプロファイルはすべて mV として扱われ、影響はありません。
- 出力単位とプロファイルの単位が違うときは、校正は保持されますが適用されません（`output_mode` は `raw`、`unit_matches` は false）。元の単位に戻せば再び適用されます。このとき `calibration_enable` は `calibration_unit_mismatch` を返します。空のプロファイルは不一致になりません。
- 新しい校正セッションは現在の出力単位で行います。保存済みプロファイルが別の単位なら下書きは空から始まり、保存すると置き換えます。セッション中は読み取りモードを変更できません（`set_range` は `calibration_session_active`）。それでも単位が変わった場合、取得と保存は `calibration_unit_changed` を返します。
- 保存済みの圧力点が別の単位のとき、単独のゼロ点取得は `calibration_unit_mismatch` を返します。
- µS の読み出しカーブは恒等式に固定です。取得中に ADC が飽和したサンプルは飽和として記録され、大半のブロックで飽和が見られた圧力点はフィットから外れます。Rfb のない行のセンサーは `no_rfb`（点の状態 `r`、`cells_no_rfb` の数）とされ、失敗には数えません。
- 状態に `unit`、`active_unit`、`unit_matches`、`draft_unit` を追加しました。

## 互換性

- range フィールドを知らない旧版の Desktop / NH Studio は、マトリクスの形状が分からない場合にセンサー数を推定できないことがあります。Desktop v1.14.0 / NH Studio v2.10.0 にあわせて更新してください。
- ほかのボードの動作は変わりません。
