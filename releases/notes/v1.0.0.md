# v1.0.0

第一個 1.0 版本。核心改動是把原本散在 `loop()` 與 `setup()` 裡的硬編碼呼叫串，抽成一層可量測、可回報、可監督的核心層，並把對外顯示的品牌short label 統一縮寫為 NHOS。

## 核心層（kernel layer）

- **Scheduler** — 以任務表取代 `loop()` 的硬編碼呼叫串。刻意不使用 FreeRTOS task：全韌體共用狀態且完全沒有鎖，只有單執行緒才安全。這層帶來的價值是計量與可觀測性，不是併發。派送順序即註冊順序，因此行為與舊 `loop()` 等價。
- **ServiceManager** — 為 `setup()` 啟動的模組加上監督。過去模組初始化失敗只會留下一行 log 然後整個開機週期都消失（例如 I2C 卡死就等於永久 `imu.setEnabled(false)`）；現在「降級運行」成為可查詢的明確狀態，並帶重試策略。
- **AppManager / App** — 應用的安裝、派送與隔離。每個 `onFrame()` 都對照其宣告的預算計時，連續超時達 `kMaxConsecutiveOverruns` 次即移出派送列表。權限集合在 manifest 中預先宣告，執行前即可檢視。
- **PowerGovernor** — CPU 頻率的唯一擁有者。硬性約束：**矩陣掃描進行中絕不降頻**（掃描路徑是 `delayMicroseconds(settleUs)` + `analogRead()`，延遲雖有頻率補償但迴圈本身沒有）。
- **Watchdog** — 包裝 loop-task watchdog，讓同時在 `setup()` 與 `loop()` 中執行的程式碼都能安全餵狗。修正 `enableLoopWDT()` 訂閱前呼叫 `feedLoopWDT()` 會以 20Hz 灌爆開機 log 的問題（實機上會讓 `magnetometer_ready` 之後的每個開機階段整段消失）。
- **FaultRecorder** — 開機時重建**上一次**執行的死當現場。崩潰當下不寫入任何東西（panic handler 是最不該碰 NVS 的地方）；重置原因由 RTC watchdog/panic 暫存器取得，task 名稱與錯誤 PC 由 coredump 分區解析。
- **AirtimeArbiter** — ESP-NOW 發送的單一收斂點，為所有競爭無線電 airtime 的路徑建立優先級分類，取代原本手寫的 if 判斷。
- **ConfigRegistry** — 以宣告式描述每個設定項。寫入時不重新實作驗證，而是合成既有 `set_*` handler 所接受的請求並轉發，讓該 handler 維持範圍檢查、持久化與套用的唯一擁有者。
- **ProcFs** — 疊在既有 file 命令之上的唯讀合成 `/proc` 範圍，所有讀取都對即時狀態執行產生器，不儲存任何內容。刻意不新增命令介面：`file_list` / `file_read_begin` / `file_read_chunk` 已存在且已接上 Desktop terminal，因此 `cat /proc/tasks` 在註冊當下即可用，無需協定或 backend 變更。

## 內建應用

- **FeatureExtractorApp** — 將整張壓力圖化約為實際被分析的幾個數值：總力、接觸面積、峰值與壓力中心。v1.5.F 一幀為 196 個 float，這五個純量在 Direct 模式下比原始幀便宜約 100 倍。
- **RuleEngineApp** — 以 Total / Peak / RegionSum / ActiveCells 等運算子在裝置端評估規則。

## NHOS 品牌縮寫

對外顯示的**短標籤**統一縮寫為 NHOS；長文說明、log 與程式註解維持原樣。

- 預設裝置名：`New Horizons OS-<UID>` → `NHOS-<UID>`
- 設定用 SoftAP SSID：`NewHorizonsOS-<MAC>` → `NHOS-<MAC>`
- 設定入口網域：`newhorizons.os` → `nhos.os`，頁面標題改為「NHOS Wi-Fi Setup」
- 產品識別字：`New Horizons OS Arduino` → `NHOS Arduino`（OTA manifest 的 `product` 欄同步；裝置端不校驗此欄，既有已發布 manifest 不受影響）

線上協定識別字 `NHO/Arduino/1` 與硬體型號字串未更動。Desktop backend 同時接受新舊兩種預設裝置名前綴，因此仍在執行 v1.0.0 之前韌體的裝置不會被誤判為使用者自訂暱稱。
