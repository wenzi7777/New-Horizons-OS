# v1.21.0

**Support for the new TIA-CTL v2.0.F board, and a fix for the on-board status LEDs flickering during animations.**

## New board TIA-CTL v2.0.F

- Adds the v2.0.F board (`arduino-v20f` update track). Same matrix and pins as v1.5.F (14 × 14).
- **Vref** comes from the on-board DAC (MCP4725). At boot the firmware reads the DAC's EEPROM and writes it once only when it is not 330 mV (factory is 1.65 V); later boots do not rewrite it.
- Before a restart, OTA reboot, pairing restart or soft-off, Vref always returns to 330 mV. `set_vref` writes the DAC register only, never the EEPROM; the default ceiling is 800 mV and can be changed with `limit_mv` (up to 2000 mV).
- **Calibration switch**: the new `calibration_switch` command drives the PCA9536 IO0 (Q1). It is always off after a reboot.
- **Battery identification**: BAT_ID is read once at boot. ID resistors of 39k / 68k / 100k / 150k on the battery mean 200 / 400 / 500 / 600 mAh (charge current 100 / 200 / 350 / 350 mA) and override the manual setting. With no resistor (JST) or any other value the manual setting applies as before.
- New `i2c_scan` command lists the I²C addresses that answer; `status` gains `vref` and `battery` gains `battery_id`.

## On-board status LEDs

- The two status LEDs on v1.5.F and v2.0.F (WS2812B-2427-V6) used Adafruit's standard timing, which is outside the V6 data sheet limits and showed random colours and full white during animations. They now use the same V6 timing (RMT) as the external strip.

## Compatibility

- Other boards are unchanged. A v2.0.F updates only from its own track.
- Pairs with Desktop v1.6.0 (recognises v2.0.F, shows the battery ID and Vref).
