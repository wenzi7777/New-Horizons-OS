# v2.0.0

**App 改由裝置上的 bytecode 虛擬機（NHVM/1）執行，取代 flow 圖直譯器；功能不變，App 需更新為 2.0.0 版。**

## App 虛擬機

- 所有 App 都改跑 App Library 編譯出的 bytecode 映像檔（套件內的 `vm`）。原本的 flow 運算子成為虛擬機的原生指令，行為逐值相同（App Library 的 C/JS 一致性測試逐位元比對）。
- 安裝與啟用時由裝置端驗證器檢查映像檔：跳躍目標、堆疊深度、變數區索引、宣告的權限，任何一項不符就拒絕。
- 每次執行有時間片：超過分配時間的處理會暫停、下次再續跑，不會延誤掃描；期間錯過的幀以 `frames_skipped` 事件回報，不會無聲漏掉。

## 記憶體

- 四個 App 位置改共用一塊 4 KB 靜態記憶池（目前 Library 的 App 每個不到 640 B），執行中不配置 heap。放不下時啟用會回 `app_pool_exhausted`。
- 直譯器的熱路徑放在 IRAM：從 flash 執行時大部分時間耗在 cache miss。v2.0.F 實測四個 App 每幀合計 263 µs（v1.23.0 為 370 µs），靜態 RAM 與舊版相當。
- `memory_status` 新增 `heap_min_largest_free_block`：最大連續可用區塊的歷史最低值，用來觀察記憶體碎片化。

## 相容性

- v2.0.0 之前建置的 App 套件沒有映像檔，狀態會顯示 `needs_update`，請從 App Store 重新安裝 2.0.0 版。
- App 版本改變，`persist` 計數會從 0 開始。
- 2.0.0 版 App 需要 v2.0.0（或之後）的韌體。
