# v2.0.0

**App はデバイス上のバイトコード仮想マシン（NHVM/1）で実行されるようになり、flow グラフのインタプリタを置き換えました。機能は同じですが、App は 2.0.0 版への更新が必要です。**

## App 仮想マシン

- すべての App は App Library がコンパイルしたバイトコードイメージ（パッケージの `vm`）を実行します。従来の flow 演算子は仮想マシンのネイティブ命令になり、挙動は値ごとに同一です（App Library の C/JS 一致テストでビット単位で比較）。
- インストール時と有効化時に、デバイス側の検証器がイメージを検査します：ジャンプ先、スタック深さ、変数領域のインデックス、宣言された権限。一つでも合わなければ拒否します。
- 実行ごとにタイムスライスがあり、割り当て時間を超えた処理は一時停止して次回に再開します。スキャンを遅らせることはなく、その間に見逃したフレームは `frames_skipped` イベントとして報告されます。

## メモリ

- 4 つの App スロットは 4 KB の静的メモリプールを共有します（現在の Library の App はどれも 640 B 未満）。実行中にヒープを確保しません。入りきらない場合、有効化は `app_pool_exhausted` を返します。
- インタプリタのホットパスは IRAM で実行します。flash から実行すると大半の時間がキャッシュミスに費やされていました。v2.0.F で 4 つの App の 1 フレームあたり合計は 263 µs（v1.23.0 は 370 µs）、静的 RAM は旧版とほぼ同じです。

## 互換性

- v2.0.0 より前にビルドされた App パッケージにはイメージがなく、状態は `needs_update` と表示されます。App Store から 2.0.0 版を再インストールしてください。
- App のバージョンが変わるため、`persist` のカウントは 0 から始まります。
- 2.0.0 版の App には v2.0.0 以降のファームウェアが必要です。
