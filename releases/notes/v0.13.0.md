# v0.13.0

## Changes

### Improved: ESP-NOW link now runs at a much faster PHY rate

- The ESP-NOW link to a New Horizons Hub ("New Horizons Direct" transport,
  added in v0.12.0) previously ran at ESP-NOW's default rate
  (`WIFI_PHY_RATE_1M_L`, 1Mbps 802.11b) — a conservative default chosen for
  compatibility, not speed. `EspNowPairing` now configures the Hub peer's
  link to `WIFI_PHY_RATE_MCS3_LGI` (~26Mbps) via
  `esp_now_set_peer_rate_config()`, real-hardware validated: clean
  (`loss=0.0%`) well past the previous ~20-25fps ceiling (up to and
  including the 40fps target tested), and usable (<2% loss) at ~6m through
  a wall on battery power. See `firmware/spikes/README.md`'s "PHY rate
  config" section for the full measurement table.
- Non-fatal if the rate-config call fails on a given board/core — falls
  back to the default rate rather than blocking pairing.
- No protocol or frame-format changes; existing paired devices/Hubs keep
  working, this only changes the transmit rate for one side of the link
  (the Hub side needs the matching `New-Horizons-Hub` release to configure
  its own side of the link the same way).
