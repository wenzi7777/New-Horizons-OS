# v1.21.0

**支援新板 TIA-CTL v2.0.F，並修正板載狀態燈在動畫時亂閃。**

## 新板 TIA-CTL v2.0.F

- 新增 v2.0.F 板型（`arduino-v20f` 更新軌道）。矩陣與腳位同 v1.5.F（14 × 14）。
- **Vref**：由板上的 DAC（MCP4725）輸出。開機時韌體讀回 DAC 的 EEPROM，只有在不是 330 mV 時才寫入一次（出廠為 1.65 V），之後每次開機都不再重寫。
- 重啟、OTA 重開、配對重啟與軟關機前，Vref 一律先回到 330 mV。`set_vref` 只寫 DAC 暫存器，不改 EEPROM；預設上限 800 mV，可用 `limit_mv` 調整（最高 2000 mV）。
- **校準開關**：新指令 `calibration_switch` 控制 PCA9536 的 IO0（Q1）。重開機後固定為關。
- **電池辨識**：開機時讀一次 BAT_ID。電池端的 ID 電阻 39k / 68k / 100k / 150k 對應 200 / 400 / 500 / 600 mAh（充電電流 100 / 200 / 350 / 350 mA），並覆蓋手動設定。沒有電阻（JST）或其他阻值時，照舊使用手動設定。
- 新指令 `i2c_scan` 列出回應的 I²C 位址；`status` 新增 `vref`，`battery` 新增 `battery_id`。

## 板載狀態燈

- v1.5.F 與 v2.0.F 的兩顆狀態燈（WS2812B-2427-V6）原本使用 Adafruit 標準時序，超出 V6 資料表的限制，動畫時會出現隨機顏色與全白。改用與外接燈相同的 V6 時序（RMT）後已修正。

## 相容性

- 其他板型的功能不變。v2.0.F 的更新檔須由 v2.0.F 專用軌道提供。
- 搭配 Desktop v1.6.0（認得 v2.0.F、顯示電池 ID 與 Vref）。
