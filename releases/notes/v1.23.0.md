# v1.23.0

**設備依品質挑選中繼、回報目前連線的優先度，並不再連上舊的 NH Gateway。**

## 挑選中繼

- 開機或原本的中繼消失（約 9 秒沒有回應）時，不再直接接受第一個回應，而是收齊 0.6 秒內的所有 offer 後挑最好的：
  1. 優先度：加入過或最後接管這台設備的中繼（主人）優先；
  2. 已連上伺服器的優先；
  3. 延遲較低的優先（相差 30 ms 內視為相同）；
  4. 服務設備數較少的優先。
- 已連線時維持不變，不會因為出現更好的中繼就自己換；只接受目前中繼的更新或被要求的轉移（接管）。

## 回報目前的中繼

- 連線中（且未在轉移）時，FindMe 會附上目前的中繼與連線時的優先度。NH Studio / Pocket / headless 據此分辨「被其他中繼接管」與「主人暫時不在、別人代為接手」，後者主人回來後會自動接回。

## 舊 NH Gateway

- 不再接受第 1 版 offer，也就是舊的 Python NH Gateway；設備不會再連上它。

## 相容性

- 需要 NH Studio / Pocket / headless v2.5.0（或之後）與 Desktop v1.9.0（或之後）：舊版送出的是第 1 版 offer，新韌體會忽略。請先更新它們。
- Hub（ESP-NOW）模式不受影響。
