# v1.22.1

**TIA-CTL v2.0.F：Rfb 量測不再被 Wi-Fi 干擾拉低、Vref 預設上限降到 700 mV，以及量程的幾個修正。**

## Rfb 量測

- 第 10–13 行接在 ADC2 上。Wi-Fi 使用中 ADC2 偶爾讀不到值，以前這次讀數會被當成 0 mV 一起平均，讓量出的 Rfb 和偏移偏低並存進裝置。現在會跳過讀不到的值；整行都讀不到時，該行標為 `adc_read_failed`，不存任何數值，請再量一次。
- 量測的最高 Vref 一律低於 750 mV，不論上限設多少。

## Vref 上限

- 預設上限從 800 mV 改為 700 mV。看門狗、電壓不足等不經正常關機流程的重開機，DAC 會保留原本的電壓；Vref 到約 800 mV 時 GPIO45 的開機判斷可能出錯，要斷電才能恢復。700 mV 保留了餘裕。已手動設定過的上限不受影響。

## 量程

- `set_range` 的 `clear_rfb`：從自動模式清除 Rfb 時，Vref 會立刻回到 330 mV（以前停在自動模式調低後的值）。
- 自動模式：停止串流超過約 1 秒後不再依舊的飽和紀錄繼續調降 Vref。
- `set_vref` 後補償立即使用新的 Vref。
- Rfb 量測或 Vref 掃描結束時，若還原 Vref 或校準開關失敗，回覆會帶 `warnings`，不再只回 ok。

## 相容性

- 只影響 v2.0.F，其他板型的功能不變。
- 搭配 Desktop v1.8.0 與 NH Studio / Pocket v2.4.0（新的 Vref 面板）。
- Wi-Fi 開啟時第 10–13 行的量測結果尚待實板確認。
