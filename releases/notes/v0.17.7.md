# v0.17.7

## v1.5.F USB CDC reliability

- v1.5.F native USB CDC 的 runtime log 改為零等待 best-effort 輸出，沒有 serial reader 或 TX buffer 已滿時不再阻塞 WebUI、掃描及 LED 更新。
- 移除暫時性的 `loop_profile` 週期報告；`scan_perf` 改為正式 build 預設關閉的編譯期診斷。
- 保留 USB flashing、Serial Monitor 與 boot/error log，不加入 watchdog 自動重啟。

## v1.5.F JST battery gauge resync

- 充電器穩定存在後，以相鄰 VCELL 變化偵測高可信度 JST 換電池事件，並對 MAX17048 執行 quick-start。
- 新增非阻塞 `resync_battery_gauge` 手動備援命令，以及 `gauge_sync_state`、`last_sync_reason`、`gauge_sync_count` 狀態欄位。
- 同步或錯誤期間不發布舊 SOC；WebUI、資料封包與板載電池 WS2812B 會共同等待有效新樣本。
- `battery_present` 在有效樣本時為 `true`，通訊或同步無效時為 `null`，不再推斷 JST 已拔除。

## Hardware-track compatibility

- v1.0.F 與所有 GCU LTS 韌體同版重建；MAX17048 同步命令僅在 v1.5.F 啟用。
