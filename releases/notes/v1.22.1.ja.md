# v1.22.1

**TIA-CTL v2.0.F：Rfb 測定が Wi-Fi の影響で低く出なくなり、Vref の既定上限を 700 mV に下げ、量程を修正しました。**

## Rfb 測定

- 10–13 行目は ADC2 につながっています。Wi-Fi 使用中は ADC2 の読み取りがときどき失敗し、以前はその値が 0 mV として平均に入り、Rfb とオフセットが低めに保存されていました。読めなかった値は除外するようにしました。1 行すべて読めなかった場合はその行を `adc_read_failed` とし、値を保存しません。もう一度測定してください。
- 測定に使う最高 Vref は、上限の設定にかかわらず常に 750 mV 未満です。

## Vref 上限

- 既定の上限を 800 mV から 700 mV に変更しました。ウォッチドッグや電圧低下など、通常のシャットダウンを通らない再起動では DAC が電圧を保ちます。Vref が約 800 mV だと GPIO45 の起動判定を誤り、電源を切るまで復帰しないことがあるため、余裕を持たせました。手動で設定済みの上限はそのままです。

## 量程

- `set_range` の `clear_rfb`：自動モードから Rfb を消去すると、Vref がすぐ 330 mV に戻ります（以前は自動モードが下げた値のままでした）。
- 自動モード：ストリーミング停止から約 1 秒たつと、古い飽和記録で Vref を下げ続けなくなりました。
- `set_vref` の直後から補正が新しい Vref を使います。
- Rfb 測定や Vref スイープの終了時に Vref や校正スイッチの復元に失敗すると、応答に `warnings` が付きます。

## 互換性

- v2.0.F のみ。ほかのボードの機能は変わりません。
- Desktop v1.8.0、NH Studio / Pocket v2.4.0（新しい Vref パネル）と組み合わせて使います。
- Wi-Fi 使用中の 10–13 行目の測定結果は実機で未確認です。
