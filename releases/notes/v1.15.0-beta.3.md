# v1.15.0-beta.3（測試版）

**建置結構調整：韌體與 Hub 共用的程式碼，改成同一份函式庫 `nhos_core`。裝置行為不變，韌體大小與 beta.2 相同。**

這是測試版，只發布在 beta 通道（`*-beta.json`）。

## nhos_core

- 新增 `firmware/libraries/nhos_core/`：板子定義（`BoardConfig.h`、`BoardPins`）、線上格式常數、`PacketWire`／`PacketV5Codec`、ESP-NOW 封包切分、對時封包、時鐘核心、版本排序、更新通道、OTA 憑證、JSON 工具、電源狀態 JSON、回覆節流與掃描延遲統計。
- Hub 不再保留這些檔案的副本，直接用同一份編譯。以前 Hub 的副本已經過時（沒指定板子時會靜默退回 v1.0.F、v2.1 的矩陣大小寫錯、缺 v1.5.F），現在這些問題隨副本一起消失。
- 所有建置、燒錄、發布腳本與 CI 都會帶 `--library firmware/libraries/nhos_core`。自己用 `arduino-cli` 編譯時也要加上。

## 相容性

- 封包、指令、回覆格式都沒變。
- 建議搭配 Hub v0.10.0-beta.1。
