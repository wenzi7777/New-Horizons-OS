# v1.23.0

**デバイスが品質で中継を選び、現在の接続の優先度を報告し、旧 NH Gateway にはつながらなくなりました。**

## 中継の選び方

- 起動時や、つながっていた中継が消えたとき（約 9 秒応答なし）、最初の応答をそのまま受けるのをやめ、0.6 秒以内の offer をすべて集めて最もよいものを選びます：
  1. 優先度：このデバイスを追加した、または最後に引き継いだ中継（持ち主）が優先；
  2. サーバーに接続中の中継が優先；
  3. 遅延が小さい中継が優先（差が 30 ms 以内なら同じとみなす）；
  4. 受け持ちデバイス数が少ない中継が優先。
- 接続中は変わりません。よりよい中継が現れても自分からは移らず、今の中継の更新か、依頼された移動（引き継ぎ）だけを受けます。

## 現在の中継の報告

- 接続中（移動中でないとき）、FindMe に現在の中継と接続時の優先度を付けます。NH Studio / Pocket / headless はこれで「他の中継に引き継がれた」と「持ち主が不在の間だけ他が受け持った」を区別し、後者は持ち主が戻ると自動で取り戻します。

## 旧 NH Gateway

- 第 1 版の offer（旧 Python NH Gateway）を受け付けません。デバイスがそれにつながることはなくなります。

## 互換性

- NH Studio / Pocket / headless v2.5.0 以降と Desktop v1.9.0 以降が必要です。旧版は第 1 版の offer を送るため、新しいファームウェアは無視します。先にそれらを更新してください。
- Hub（ESP-NOW）モードには影響しません。
