# v1.15.0-beta.2（測試版）

**純重構：韌體、Hub、Gateway、Desktop 與 App Library 共用的常數，改成各只有一份原始來源，其他地方都從它產生。裝置行為不變。**

這是測試版，只發布在 beta 通道（`*-beta.json`）。

## App 合約由 App Library 產生

- App 的 op 表（名稱、輸入數、成本、類型、需要的 capability）、capability 位元、特徵／IMU／磁力計欄位名稱與 LED 顏色，改由 App Library 的 `sdk/lib/opset.mjs` 產生成 `AppContract.h`（`nhos.mjs gen-contract`）。
- `FlowApp` 解析 op、估算成本、檢查輸入數與視窗，`AppPackage` 解析 capability，都改查這張表，不再各自手寫一份。
- op 編號與以前完全相同（持久化計數器存的是 op 編號）。CI 會檢查韌體裡的表和 App Library 產生的一致。

## 線上格式常數由 `spec/wire.json` 產生

- 埠號、封包 magic／版本／旗標／大小、對時封包的 magic 與長度，只寫在 `spec/wire.json`。`firmware/scripts/gen_wire.py` 產生韌體與 Hub 的 `PacketWireConstants.h`、`TimeWireConstants.h`，以及 Desktop 與 Gateway 的 `wire.py`。

## 平台規格

- 新增 `spec/PROTOCOL.md`：傳輸方式、指令與回覆格式、v5 封包配置、對時、App、`/proc`、更新通道與相容性規則。
- `spec/commands.md`、`spec/config.md` 由指令表與 `ConfigRegistry` 自動產生（`firmware/scripts/gen_spec_docs.py`），CI 會檢查是否最新。

## 相容性

- 封包、指令、回覆格式都沒變。
