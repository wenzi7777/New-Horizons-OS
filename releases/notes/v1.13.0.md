# v1.13.0

**`health` 新增 ESP-NOW（Direct 模式）連線品質統計。**

## ESP-NOW 連線品質

`health` 的 `connectivity` 區塊新增三個累計值。和其他統計一樣存在裝置上，不會被任何指令清除：

- `espnow_hub_losses`：與 Hub 斷線的次數。已配對，但超過 10 秒沒收到 Hub 的任何訊息（POLL、PAIRED 或其他）就算一次；同一段斷線只算一次。
- `espnow_reply_failures`：指令回覆送不出去的次數，也就是重送到上限後放棄的回覆。
- `espnow_send_failures`：無線電回報送達失敗的次數。包含感測資料串流，這類丟包本來就會有，只用來看趨勢。

`/proc/health` 也同步輸出這三個值。Desktop v0.21.0 起，經 Hub 連線的裝置會在健康卡片顯示它們。

## 相容性

- 統計格式升到 schema 2，只在尾端新增欄位。舊的統計會照常讀取，新欄位從 0 開始。
- 降級回舊韌體時，統計會重新開始，和以往的格式變更一樣。
