# v1.21.0

**新基板 TIA-CTL v2.0.F に対応し、基板上のステータス LED がアニメーション中にちらつく問題を修正しました。**

## 新基板 TIA-CTL v2.0.F

- v2.0.F を追加(`arduino-v20f` 更新トラック)。マトリクスとピンは v1.5.F と同じ(14 × 14)。
- **Vref** は基板上の DAC(MCP4725)が出力します。起動時に DAC の EEPROM を読み戻し、330 mV でない場合に限り 1 回だけ書き込みます(出荷時は 1.65 V)。以降の起動では書き直しません。
- 再起動、OTA 再起動、ペアリング再起動、ソフトオフの前に、Vref は必ず 330 mV に戻ります。`set_vref` は DAC レジスタのみに書き込み、EEPROM は変更しません。上限は既定 800 mV で、`limit_mv` で変更できます(最大 2000 mV)。
- **校正スイッチ**:新コマンド `calibration_switch` が PCA9536 の IO0(Q1)を制御します。再起動後は必ずオフです。
- **バッテリー識別**:起動時に BAT_ID を 1 回読みます。電池側の ID 抵抗 39k / 68k / 100k / 150k は 200 / 400 / 500 / 600 mAh(充電電流 100 / 200 / 350 / 350 mA)に対応し、手動設定より優先されます。抵抗なし(JST)やその他の値では従来どおり手動設定です。
- 新コマンド `i2c_scan` で応答する I²C アドレスを確認できます。`status` に `vref`、`battery` に `battery_id` が加わりました。

## 基板上のステータス LED

- v1.5.F と v2.0.F の 2 つのステータス LED(WS2812B-2427-V6)は Adafruit の標準タイミングを使っており、V6 データシートの範囲外のため、アニメーション中にランダムな色や全白になっていました。外付けストリップと同じ V6 タイミング(RMT)に変更して修正しました。

## 互換性

- 他の基板の機能は変わりません。v2.0.F は専用トラックからのみ更新されます。
- Desktop v1.6.0(v2.0.F の認識、電池 ID と Vref の表示)と組み合わせてお使いください。
