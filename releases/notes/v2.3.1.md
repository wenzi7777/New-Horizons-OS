# v2.3.1

**WiFi 模式的設備可用記憶體（heap）增加約 44 KB，最大連續區塊約加倍。**

## 記憶體

- ESP-NOW（New Horizons Direct）用的配對、串流、OTA 轉送與無線電排程緩衝，共約 44 KB，以前不論哪種傳輸模式都固定保留。現在只有以 ESP-NOW 模式開機時才配置；WiFi / UDP 模式的設備把這塊留給 heap。
- v2.0.F 實測（WiFi、14×10、無 App、各 10 分鐘）：可用 heap 中位數 105.0 → 159.8 KB，最大連續區塊 36.9 → 73.7 KB，掃描 fps 與掉幀不變。
- ESP-NOW 模式的總用量不變；只是這塊從靜態記憶體移到開機時配置，`memory_status` 的 `heap_free` 讀數因此比以前少約 44 KB，屬正常現象。
- 若 ESP-NOW 模式開機時配置失敗（記憶體不足，正常情況不會發生），設備改以 WiFi 模式開機（有已存 WiFi 就連線，否則開設定頁），並記錄 `espnow_alloc_failed`。

## 相容性

- WiFi 模式下 `status` / `sysmon` 的 `airtime` 為 `{}`，能力清單的 `airtime_arbiter` 為 `false`（這個排程器只服務 ESP-NOW）。
- 協定與指令都沒有改變，可與現有 Desktop、NH Studio / Pocket / headless、Hub 混用。
