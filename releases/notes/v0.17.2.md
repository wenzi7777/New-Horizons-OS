# v0.17.2

## All Arduino hardware tracks are aligned

- VD-CTL/R v1.0.F 2026.4
- VD-CTL/R v1.5.F 2026.7
- VD-CTL/R v2.3.D GCU LTS
- VD-CTL/R v2.2.C GCU LTS
- VD-CTL/R v2.1 GCU LTS

Every track now publishes the same firmware version, but retains a dedicated
OTA manifest and firmware artifact so a device can only receive its matching
hardware image.

## v1.5.F LED behavior

On v1.5.F, the system WS2812B no longer mirrors charging state. It shows the
normal connection state, including the blue breathing FindMe/gateway-pending
state. The dedicated battery WS2812B remains responsible for charge and
battery indication.

## Release tooling

All Arduino release scripts now emit both latest and versioned manifests for
their own hardware track and compile the requested release version into the
firmware image.
