# v0.17.4

## v1.5.F FPC 3.0 external LEDs

- The nine external WS2812B-2020-V6 LEDs now use a dedicated GPIO16 RMT
  transmitter, so their frames cannot conflict with the two-pixel GPIO46
  onboard status/battery chain.
- The V6 data pulses are now 300/1000 ns for a zero and 700/600 ns for a one,
  matching the component's timing envelope. This fixes the static white or
  random-color output seen with FPC 3.0.
- The external LED status now reports `transport:"dedicated_rmt"` and
  `rmt_ready` for field diagnostics.

## Hardware-track compatibility

- v1.0.F keeps its established FPC 2.0 Adafruit WS2812 output path and timing.
- GCU LTS tracks are rebuilt at the same release version with their existing
  model-specific artifacts and OTA manifests.
