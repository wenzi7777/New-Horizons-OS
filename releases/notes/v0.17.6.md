# v0.17.6

## v1.5.F Action Button

- 新增可持久化的 Action Button 設定：短按可設為無動作、裝置辨識或切換外接 LED；長按額外可設為 soft-off。
- 預設行為維持原有體驗：短按無動作，長按進入 soft-off。
- 開機藍燈期間的單按 Wi-Fi 設定，以及 soft-off 時的短按喚醒，維持固定行為且不可由設定覆寫。
- `status` 現在會回報 `action_button` 支援狀態、設定值及最近執行結果；`set_action_button` 僅接受 v1.5.F 的合法組合。
- 裝置辨識會閃爍板載狀態燈；外接 LED 已啟用時，也會顯示既有辨識效果。切換外接 LED 會保留 preset、亮度與顏色，並持久化最後狀態。

## Hardware-track compatibility

- v1.0.F 與所有 GCU LTS 韌體同版重建，保留既有按鍵與電源行為；Action Button 設定不會在這些板型啟用。
