# v2.3.0

**設備與 relay 的連線改成要續約的「租約」：設備會持續確認自己的 relay 還在，relay 關閉、換 IP 或被接管時約 15 秒內自動找到新的 relay，不必再手動按「發現設備」。**

## FindMe 租約

- **搜尋中**（剛開機、relay 遺失、轉移中）：與以前相同，每 3 秒廣播 `findme_discover`，並單播給上次的 relay。
- **已附著**：每 5 秒單播一次 discover 給目前串流的 relay（帶 `current_gateway_id` / `current_priority`），relay 回 offer 即續約。每第 3 次另外廣播一次（信標），讓擁有這台設備的 relay 知道它在哪裡；其他 relay 不會回應。`findme.state` 續約期間維持 `attached`。
- **遺失**：連續 3 次續約沒有回應（relay 停止回應後 15–20 秒），回到搜尋並重新選擇 relay；接受新的 offer 前仍往舊位址串流，舊 relay 若恢復回應就直接留下。以前的韌體附著後就不再送 discover，relay 關閉後會一直往舊位址送資料。
- `findme_switch_gateway`（接管）期間，discover 也單播給送出這個指令的位址，不擋廣播的網路也能完成接管。逾時（預設 30 秒）後恢復與原本 relay 的租約。
- `findme_probe` 的回應改為依詢問位址各自節流（每個位址 5 秒一次，最多記 4 個），多台 relay 同時探索時不會互相吃掉回應。

## 相容性

- 訊息格式與優先權規則不變，新舊韌體、新舊 NH Studio / Pocket / headless 與 Desktop 可以混用。搭配 NH Studio v2.11.0 效果最好（已添加的設備不必按探索就會列出並自動找回）。
