# v0.17.3

## System indication

- System LED is solid blue for the first three seconds after boot.
- Direct Wi-Fi devices breathe blue while searching for a Gateway; ESP-NOW
  devices breathe orange while searching for a Hub.
- A failed automatic OTA download remains visible in serial and status, but
  no longer replaces connectivity discovery with a red error burst.
- Command feedback is now a sequence: blue acknowledgement, mint success or
  red failure, then the normal system state.

## v1.5.F battery indication

- The dedicated battery WS2812B now changes continuously from orange at 0%
  to green at 100%.
- During charging it flashes while retaining the live state-of-charge color.
- The onboard system and battery LEDs default to 30% brightness; this can be
  changed using the `set_indicators` board LED brightness setting.

## Hardware tracks

All Arduino hardware tracks remain on dedicated, model-specific artifacts
and OTA manifests at the same release version.
