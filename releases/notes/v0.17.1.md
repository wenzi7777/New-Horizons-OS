# v0.17.1

## Critical OTA version-reporting fix for VD-CTL/R v1.5.F 2026.7

The v0.17.0 v1.5.F binary was built while its embedded firmware version still
reported `v0.16.1`.  With automatic OTA enabled, it therefore treated the
v0.17.0 manifest as newer on every boot and repeatedly reapplied the same
image.

This release injects the release `VERSION` into the compiled firmware.  The
v1.5.F binary now reports `v0.17.1`, matching its manifest.  A v0.17.0 device
that is online will fetch v0.17.1 once; after restarting it will see itself as
current and stop updating.

All Arduino release scripts now use the same version-injection mechanism, so
future published binary filenames, manifests, and runtime version reports stay
in sync.
