# v1.20.0

**A device stays with the host it is attached to instead of hopping between NH Studio and NH Pocket.**

## Cause

- A device sends FindMe every 3 seconds. Even when attached it took the first offer of each round (or any higher-priority offer), so with two hosts managing it, it switched hosts on reply timing.

## Fix

- While attached it accepts only its current host, or the host a claim (Add) asked for.
- Only after the current host has not answered for 3 rounds in a row (~9 s) does it take another host's offer, moving on its own.
- A higher-priority offer no longer takes an attached device.
- A device that is not attached behaves as before: the first offer of the round.

## Compatibility

- The host-side delay in NH Studio / NH Pocket / headless v2.0.1 and later still works, also with older firmware.
- Hub (ESP-NOW) mode is not affected.
