# v1.5.0

flow App 可以**控制外置 LED 燈條**：逐顆點亮像素，或把數值顯示成沿著燈條的 meter。

## 為什麼

App 過去只能點亮板上的狀態 LED。外置燈條有 3 顆（v1.0.F）到 9 顆（v1.5.F），用來顯示
壓力大小或多個事件的狀態更直觀，而且不需要另接 OLED。

## 變更

- **新增 2 個 op**：`ext_pixel`（布林輸入為 true 的那幾幀，以指定顏色點亮第 `index` 顆）、
  `ext_meter`（依輸入在 `[lo, hi]` 的比例點亮燈條，由綠到紅漸層）。都是純量 op，每個 600 ns。
- **新增 capability `drive_ext_led`**（bit 11）。
- **執行中的 App 優先於外置 LED preset**：只要有宣告 `drive_ext_led` 的 App 在執行，燈條就改由
  App 控制，`active_preset` 顯示 `app`；App 停止後恢復原本的 preset。App 那一幀什麼都沒點亮時，
  燈條是暗的，不會閃回 preset。`mode` 為 `off` 時 App 也不會點亮，亮度設定照樣套用；
  identify、開關機動畫與休眠仍然優先。
- **畫燈不計入 App 的預算**：和 OLED 一樣，節點只記錄要顯示什麼，實際輸出由 LED service 負責，
  內容未變時不重送。燈條每幀依實際執行到的節點重建，所以關閉的 `gate` 裡的像素會熄滅。
- **組合規則**：像素疊在 meter 上面（`off` 也算顏色，可以在 meter 上挖出暗點）。多個 App
  同時執行時，meter 取自編號最小、有 meter 的槽位；每顆像素取自編號最小、點亮它的槽位。
- 像素編號 0–8；超出板子實際數量的像素會被接受但不顯示，所以同一個套件在兩塊板子上都能跑。
  GCU LTS 系列沒有燈條，App 照常執行但沒有東西可顯示。
- 燈條內容的計算集中在新的 `AppExtLed.cpp`。App Library 的 `sdk/lib/extled.mjs` 以 float32
  逐步對應，契約測試會把這個檔案編譯成本機程式逐值比對。

## 驗證

- 5 塊板子的 release build 均通過；`tests/` 靜態測試通過。
- App Library 的 188 項測試通過，其中包含與本版韌體原始碼的契約測試（含 C++ 編譯比對）。
- **本版尚未經過實機驗證**：燈條接管與交還、meter 漸層與亮度需要在 v1.0.F / v1.5.F 上確認。

## 相容性

- 使用 `pixel` 或 `meter` 的套件需要本版本；App Library 會自動推算 `min_os: v1.5.0`，
  舊韌體會以 `min_os` 拒絕安裝。
- 既有套件與外置 LED 設定不受影響。
