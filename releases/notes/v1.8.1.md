# v1.8.1

**板子型號再改名：TIA-CTL/R → TIA-CTL。** 裝置回報的 `hardware_model` 現在是 `TIA-CTL …`，例如 `TIA-CTL v1.5.F 2026.7`。

## 為什麼

名稱裡的「/R」原本指跨阻級的回授電阻 Rfb。電路上 Rfb 仍然存在，但名稱不再標示它。TIA 是 TransImpedance Amplifier（跨阻放大器）。PCB 不改名。

## 變更

- 5 塊板子的 `NHOS_BOARD_NAME` 拿掉「/R」。status、FindMe、`/proc` 的 `hardware=` 都跟著改。
- Windows 燒錄腳本顯示的板名和 README 改成 TIA-CTL。
- **OTA 不受影響**：manifest 的 `model` 仍是改名前的 `VD-CTL/R …`（`NHOS_BOARD_OTA_MODEL`）。v1.7.5 以前的版本和 v1.8.0 都接受這個名稱，可以直接 OTA 到這版。

## 驗證

- 5 塊板子的 release build 均通過；`tests/` 靜態測試全部通過。
- **本版尚未經過實機驗證**：v1.7.5 或 v1.8.0 的板子 OTA 到 v1.8.1 應該成功，之後 Desktop 應顯示 `TIA-CTL …`。

## 相容性

- **Desktop 要先更新到 v0.15.1**。v0.15.0 以前的 Desktop 認不出 `TIA-CTL …`，會把這塊板子當成 v1.0.F 預設設定。
- 指令與回應格式不變。
