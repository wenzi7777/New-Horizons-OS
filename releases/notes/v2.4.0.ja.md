# v2.4.0

**IMU と地磁気センサーのサンプリングレートがスキャンレートに連動するようになりました。地磁気センサーにはオン/オフ（既定はオフ）とハードアイアン/ソフトアイアン校正を追加し、再校正の時期をお知らせします。**

## サンプリングレートのスキャン連動

- IMU と地磁気センサーの読み取り間隔はスキャン間隔（`scan.target_fps`）と同じになり、チップの ODR も合わせて設定されます（以前は固定値）。
- BMI270、BMM350：ODR は 25 / 50 / 100 / 200 Hz のうち fps 以上で最小の値です。BMM350 の平均回数は ODR に応じて 8 / 8 / 4 / 2 です。
- BMM150：ODR は 10 / 15 / 20 / 25 / 30 Hz から選び、上限は 30 Hz です。それより高い fps では同じ値が繰り返し読まれます。
- 以前は BMI270 が 100 Hz、BMM350 が 25 Hz に固定され、地磁気センサーは 50 ms ごとに読み取っていたため、高い fps では地磁気のサンプルが欠けていました。
- `status` の追加項目：IMU は `odr_hz`、地磁気センサーは `odr_hz`、`averaging`、`poll_interval_us`、`measured_rate_hz`。

## 地磁気センサーのオン/オフ

- 新コマンド `set_mag`：`enabled` で地磁気センサーをオン/オフし、`cal_interval_days` で校正リマインダーの間隔（0〜365 日、既定 30、0 で通知なし）を設定します。設定は保存され、再起動後も保持されます。
- **既定はオフで、このバージョンに更新した後もオフです。** オフのときは読み取りを行わず、ストリームに mag を含めず、チップは省電力モードになります。
- 地磁気センサーのないボード（v1.0.F）は `magnetometer_not_supported` を返します。GCU で IMU がオフのとき、地磁気センサーは `blocked_by: imu` を返します。
- Desktop / NH Studio / NH Pocket で地磁気センサーをオンにすると、そのまま校正ウィザードが開きます。校正を適用せずに閉じると自動的にオフに戻ります。

## ハードアイアン/ソフトアイアン校正

- 新コマンド `set_mag_calibration`：`offset`（µT）と 3×3 の `matrix` を保存します。計算式は `m_cal = M · (m_raw − b)` です。`{clear:true}` で校正を消去します。ファームウェアは値の範囲、行列式、条件数を検証します。
- 校正はストリーム、`sensor_sample`、App の `mag()` に適用されます。`sensor_sample` は未校正の `mx_raw` / `my_raw` / `mz_raw` も返します。
- 校正は設定に保存され、factory reset で消去されます。

## 校正ずれの疑い

- 校正後の |m| の 60 秒中央値が校正時の磁場強度から 20% 以上ずれた状態が 5 分続くと、`calibration.suspect` が `true` になり、App が再校正を勧めます。5 分間正常に戻るか再校正すると解除されます。RAM のみに保持し、地磁気センサーの停止や校正の消去は行いません。

## 互換性

- `status.magnetometer` の `"calibration":"available"` は `"compensation":"factory"|"unavailable"` に名前が変わりました。`calibration` は校正内容のオブジェクト（`mode`、`offset`、`matrix`、`field_ut`、`residual_pct`、`calibrated_at_ms`、`interval_days`、`suspect`）になりました。
- Desktop v1.18.0 / NH Studio v2.15.0 と組み合わせると、オン/オフ、校正ウィザード、期限リマインダーを使えます。古い App もそのまま使えますが、これらの機能は表示されません。
