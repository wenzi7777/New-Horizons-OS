# v2.1.0

**App 可以寫成命令式程式（TypeScript 風格），並新增系統呼叫：儲存、App 間訊息、裝置設定與串流，以及 v1.5.F / v2.0.F 的外接 I2C / UART。危險權限必須在安裝時由操作者同意。**

## App 系統呼叫

- **儲存**（`storage`）：每個 App 最多 16 個數值（`store.get` / `store.set`，存在 NVS，最多每 30 秒寫一次、停止時寫入），以及 CSV 檔（`store.append`，寫到 appdata 範圍的 `<id>/<檔名>.csv`）。每個 App 的檔案合計上限 16 KB；超過時該列被拒絕並發出一次 `store_full` 事件，不會中止 App。寫入經過每個 App 256 B 的固定緩衝，滿了或每 10 秒才寫 flash。
- **App 間訊息**（`app_ipc`）：`app.publish(topic, 值)` 送給其他以 `on("message", topic, …)` 訂閱的 App；每個 App 佇列 4 筆，滿了計入 `events_dropped`。
- **裝置設定**（`device_config`）：App 執行期間可改 `scan.target_fps`、`scan.send_every_n_frames`、`filter.enabled/median/alpha`、`imu.enabled`，範圍與一般設定相同、每秒最多一次、**不寫入 NVS**；App 停止、出錯或被移除時還原原值。
- **串流**（`device_stream`）：`device.stream(false/true)` 暫停 / 恢復送往 relay 的串流；App 停止時自動恢復。
- **外接 I2C**（`io_i2c`，僅 v1.5.F / v2.0.F）：7-bit 位址，板上晶片（0x14、0x36、0x3C/0x3D、0x41、0x60、0x68、0x6A）一律拒絕；單筆最多 32 B、逾時 5 ms，NACK 回傳 -1 而不中止 App，傳輸時間計入該 App 的時間片。
- **外接 UART**（`io_uart`，僅 v1.5.F / v2.0.F）：FPC1.17 TX / FPC1.16 RX，1200–921600 baud；驅動與 256 B 接收緩衝只在開啟期間存在，App 停止時自動關閉、腳位回到輸入。
- 陣列參數在系統呼叫內檢查範圍，越界即 `bad_syscall_arg` 錯誤。執行期間仍然不配置 heap。

## 權限與同意

- 權限位元擴為 32 位，新增 `storage`、`app_ipc`、`device_config`、`device_stream`、`io_i2c`、`io_uart`。
- `app_install` 新參數 `grant`（字串陣列）。宣告了危險權限（storage、device_config、device_stream、io_i2c、io_uart）卻沒有被授權的套件會被拒絕（`capability_not_granted:<權限>`）；板子沒有的 I/O 也會被拒絕（`capability_unsupported:<權限>`）。授權存入套件索引，`app_list_packages` 以 `granted` 回報。
- 移除 App 時一併清除它的數值與 appdata 檔案。

## 相容性

- App Library 3.0.0 的 App 改用 TypeScript 風格的原始碼編譯，需要 v2.1.0 韌體；2.0.0 版的 App 在 v2.1.0 上照常執行。
- 安裝 3.0.0 App 需要 New Horizons Desktop v1.12.0 / NH Studio v2.8.0 以上（舊版無法驗證沒有 `nodes` 的套件，也不會送出 `grant`）。
